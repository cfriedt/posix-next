POSIX_C_LANG_WIDE_CHAR
======================

The ``POSIX_C_LANG_WIDE_CHAR`` Option Group is included in the ISO C standard.

.. note::
   When using Newlib, Picolibc, or other C libraries conforming to the ISO C Standard, the
   ``POSIX_C_LANG_WIDE_CHAR`` Option Group is considered supported.

Please refer to `Subprofiling Considerations <https://pubs.opengroup.org/onlinepubs/9699919799/xrat/V4_subprofiles.html>`_ for details on the ``POSIX_C_LANG_WIDE_CHAR`` Option
Group.
